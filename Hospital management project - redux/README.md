# Hospital Management System

A simple Hospital Management System built using React.js and Redux Toolkit.

## Technologies Used

- React.js
- JavaScript
- Redux Toolkit
- React Redux
- React Router
- JSON Server
- HTML
- CSS

## Features

### Patient Management
- Add patients
- View patients
- Delete patients

### Doctor Management
- Add doctors
- View doctors
- Delete doctors

### Appointment Management
- Add appointments
- View appointments
- Delete appointments

### Dashboard
- View total number of patients
- View total number of doctors
- View total number of appointments

## Redux Concepts Used

- Redux Store
- createSlice
- Actions
- Reducers
- useSelector
- useDispatch

## Data Storage

The project uses JSON Server and `db.json` to store:

- Patient details
- Doctor details
- Appointment details
